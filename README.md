# 🥤 Máquina Expendedora en C#

Simulador de máquina expendedora de sodas desarrollado en C# como práctica escolar.

## Descripción
Este programa simula una máquina expendedora donde el usuario puede insertar dinero, elegir una bebida del menú y recibir su cambio.

## Cómo ejecutarlo
1. Abre el archivo MaquinaExpendedora.cs en Visual Studio
2. Dale clic en Run / Ejecutar
3. Sigue las instrucciones en pantalla
